# Car Sales Analysis Using Python

## Project Overview
This project analyzes a car sales dataset using Python, Pandas, and NumPy.

## Objectives
- Clean and preprocess sales data
- Perform descriptive statistical analysis
- Analyze sales performance
- Identify top-selling vehicles
- Generate business insights from data

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
